# Security policy

## Supported versions

The latest published `@releval/tracker` release receives security fixes.
Older versions do not.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub, using
[Report a vulnerability](https://github.com/releval/tracker/security/advisories/new)
on this repository's Security tab.
If that is not available to you, email `hello@releval.co` instead.

Include the affected version, what an attacker can do with the issue, and the
smallest reproduction you have. A proof of concept is welcome but not required.

You should get an acknowledgement within a few working days.
We will tell you what we intend to do and when, and credit you in the advisory
unless you would rather we did not.

## Scope

This repository is the browser tracking library only.
Problems in the Releval server, its APIs or its documentation belong at
[releval/tickets](https://github.com/releval/tickets) for non-security issues,
or `hello@releval.co` for security ones.
